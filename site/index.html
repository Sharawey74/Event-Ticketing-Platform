A ticket tier can never oversell.

What this project demonstrates

Three engineering problems that are easy to get wrong at scale — solved with atomic operations instead of bigger locks.

⚡

Concurrency-safe by design

A Redis Lua script performs the availability check and decrement as one atomic operation — proven by a 100-thread test against a 50-seat tier: exactly 50 succeed, 0 oversold.

 🛡️

Production-grade reliability

An 11-state booking lifecycle, multi-replica-safe scheduled jobs, correlation-ID traced logging, and async QR/email delivery via RabbitMQ dead-letter queues.

 🔒

Real payments & security

Genuine Stripe test-mode checkout with idempotent webhook handling, RBAC plus object-level authorization, JWT denylisting, and Redis-backed rate limiting.
